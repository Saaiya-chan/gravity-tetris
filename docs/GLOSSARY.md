# グラビティ・ポップ 用語集

ゲームの中の文章・仕様書・テスト・Wiki で、同じものを同じ名前で呼ぶための一覧です。
「コード上の名前」は `free.html` の中の変数名で、テストや仕様書から参照するときに使います。

## 基本

| 用語 | 読み | 意味 | コード上の名前 |
|---|---|---|---|
| ぷに | ぷに | 盤面に落ちてくる、ねこの形のつぶ。「ぷよ」とは呼ばない | `balls` の1個 |
| 組 | くみ | いっしょに落ちてくる、ぷにのひとかたまり（2個〜） | `piece` |
| 盤面 | ばんめん | ぷにがたまる場所。四角・丸・六角形・八角形がある | `arena()` |
| 出口 | でぐち | 盤面の真ん中にある、組が出てくる場所 | — |
| 重力 | じゅうりょく | 端末を傾けた方向。ぷにはその向きに落ちる | `gN`, `gDir()` |
| つながり | — | 同じ色のぷに同士がくっついた状態。一度つながると離れない | `bonds` |
| 消す | けす | 同じ色が5個以上つながって、ぷにがはじけること | `findPops` |
| 連鎖 | れんさ | 受付時間のうちに、続けて消すこと。2回目が「2連鎖」 | `chain` |
| 連鎖の受付時間 | — | 次に消すと連鎖がつながる残り時間 | `chainWin(n)` |
| スコア | — | 消した数と連鎖で増える点数 | `score` |

## あそび方の単位

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| ワールド | 5つのステージのまとまり。草原・砂漠など10種類。最後にボスがいる | `THEMES`, `worldNo` |
| ステージ | ワールドの中の1面。「ステージ 1-3」はワールド1の3面目 | `level` |
| ワールドクリア | ワールドのボスを倒すこと | `worldClear()` |
| クリア回数 | そのワールドをクリアした回数。多いほどボスが強くなる | `worldClears[k]` |
| エンドレス | ステージごとにワールドが変わっていく、終わりのないモード | `mode==="endless"` |
| スター | ワールドごとに3つある、クリアのしかたの記録（ボスをたおした・王冠をこわした・缶なしでクリア）。全部で30。一度取ると消えず、数に応じてエネルギーの上限とスタート時エネルギーがふえる。記号は ★ | `wstars[k]`, `starsOf(k)`, `starTotal()` |
| ゲームオーバー | 出口がふさがって、次の組が出られなくなること | `gameOver()` |
| ライフ | 1回あそぶごとに1つ使うハート。最大5、20分で1つ回復 | `lives` |
| 放置ペナルティ | 操作しないでいると、お邪魔ぷにが降ってくること | `idleStep` |

## ワールド（10種類）

| ワールド | キー | 特徴 | ボス |
|---|---|---|---|
| 草原 | `meadow` | ふつうの重さ・ふつうのすべり | ぷにキング |
| 砂漠 | `desert` | ざらざらで止まりやすい | サンドキング |
| 氷 | `ice` | つるつるすべる | アイスキング |
| 炎 | `fire` | 重力が弱い | ファイアキング |
| トランポリン | `bouncy` | 壁でボヨンとはね返る | ボヨンキング |
| 宇宙 | `space` | 重力がとても弱い | コスモキング |
| べたべた | `sticky` | べたべたぷにがたくさん出る（はちみつ） | ハニーキング |
| ポップコーン | `popcorn` | 壁にふれたぷにが弾け飛ぶ | ポップキング |
| フラワー | `flower` | はなぷにが出る | フラワークイーン |
| マグマ | `magma` | マグマぷにが出る | マグマキング |

## ぷにの種類

| 用語 | 意味 |
|---|---|
| ふつうのぷに | 赤・青・緑・黄・紫の5色。同じ色が5個以上つながると消える |
| お邪魔ぷに | 灰色。何個つながっても消えない。となりでぷにが消えると巻きこまれて消える |
| 虹ぷに | どの色ともつながって、いっしょに消える |
| はなぷに | はなぷに同士としかつながらない。3個で消えて、花びらが舞う（フラワーワールド） |
| マグマぷに | だれともつながらない火の玉。ふれたぷにを、まわりごと燃やす（マグマワールド） |
| 特殊ぷに | 爆弾・感染・風船・重り・氷・磁石・時限・べたべた の8種類。ふつうのぷにに力がついたもの |

## ボス戦

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| ボス | ワールドの5ステージ目に出てくる相手。ぷにを消すと体力がへる | `boss` |
| 体力 | ボスのHP。0にすると倒せる | `boss.hp` |
| 王冠 | ボスがかぶっている冠。宝石の力で妨害をしてくる。体力とは別にじょうぶさがある | `boss.crown` |
| 妨害 | ボスがワールドごとにしてくる、じゃまな能力（砂嵐・ふぶき など） | `bossAbility` |
| いじわる光線 | ぷにキングが出口から出す光線。当たるとつながりがこわれる | `beam` |
| 弱点 | そのボスによく効くアイテム。一度使うまでは「？？？」と伏せてある | `COUNTER` |
| 見破る | ボス戦で弱点アイテムを初めて使うこと。以後、研究所に相手の名前が出る | `weakFound` |
| 封印 | 弱点アイテムを使ったあと10秒間、ボスが妨害できなくなること | `boss.sealUntil` |
| 効果ばつぐん / 効いてる / あまり効いてない | アイテムが王冠に与えるダメージの3段階 | `bossCounter` |
| 王冠をこわす | 王冠のじょうぶさを0にすること。以後そのボスは妨害できない | `crownHit` |

## 宝石・アイテム

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 宝石 | ボスを倒すともらえる、そのワールドの色の石。ワールドごとに10種類 | `gems[k]` |
| 虹の宝石 | 王冠をこわして倒すともらえる。どの宝石の代わりにもなる | `gems.rainbow` |
| ぷに研究所 | 宝石でアイテムを開発・強化する場所 | `showMenu("skills")` |
| 開発 | 宝石5個で、新しいアイテムを使えるようにすること | `develop` |
| 強化 | 宝石でアイテムのレベルを上げること | `upgrade` |
| レベル（Lv） | アイテムの強さ。Lv1から始まり、Lv5まで | `lvOf(k)`, `UP_MAX` |
| エネルギー | アイテムを使うための力。ぷにを消すとたまる。記号は ⚡ | `energy` |
| エネルギーの上限 | ためられるエネルギーの最大。100から始まり、スター1つにつき2ふえる（最大160） | `enCap()` |
| スタート時エネルギー | プレイを始めたときのエネルギー。40から始まり、スター1つにつき1ふえる（最大70） | `enStart()` |
| 消費エネルギー | アイテムを1回使うのにいるエネルギー | `enCost(k)` |
| エネルギー缶 | 持っていると、次のプレイを満タンで始められる。ショップで買う。使ったプレイでは3つ目のスターが取れない | `carry.can`, `canUsed` |
| コイン | プレイするともらえるお金。ショップで使う | `coins` |

### アイテム（6種類）

| アイテム | キー | 効果 |
|---|---|---|
| ブースター | `boost` | 連鎖の受付時間が2倍になる |
| ストップ | `stop` | 新しい組が出てこなくなる |
| マグネット | `mag` | 同じ色どうしが引き合う |
| シャッフル | `shuf` | ぷにを吸いこんで、ばらまき直す |
| ジャンプ | `jump` | 全部のぷにをはね上げる |
| 魔法の手 | `hand` | ぷにを指でつかんで運べる |

準備中のアイテム: ほうき・はじけ玉・おもし・ひのたま・じょうろ

## そのほか

| 用語 | 意味 |
|---|---|
| アバター | プロフィールに出る自分のぷに。からだの色と、デコでできている |
| デコ | アバターにつける飾り（あたま・かお・とくせい） |
| フレーム | アバターのまわりの枠 |
| デイリー | 1日1回もらえるごほうび。7日でひとめぐり |
| 図鑑 | 出会ったぷにの記録 |
| 開発版 / 製品版 | 開発版は全部のアイテムやボス戦を試せる。App Store に出すのは製品版 |

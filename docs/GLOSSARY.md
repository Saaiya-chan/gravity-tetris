# グラビティ・ポップ 用語集

ゲームの中の文章・仕様書・テスト・Wiki で、同じものを同じ名前で呼ぶための一覧です。
「コード上の名前」は `free.html` の中の変数名で、テストや仕様書から参照するときに使います。

## 基本

| 用語 | 読み | 意味 | コード上の名前 |
|---|---|---|---|
| ぷに | ぷに | 盤面に落ちてくる、ねこの形のつぶ。「ぷよ」とは呼ばない | `balls` の1個 |
| 組 | くみ | いっしょに落ちてくる、ぷにのひとかたまり（2個〜） | `piece` |
| NEXT | ネクスト | 次に出てくる組の予告。画面の右上の箱に出していたが、いまは非表示（その場所に、ぷに妖精の顔がいる）。次の組そのものは、今までどおり作られている | `nextPairs`, `SHOW_NEXT` |
| 盤面 | ばんめん | ぷにがたまる場所。四角・丸・六角形・八角形がある | `arena()` |
| 出口 | でぐち | 盤面の真ん中にある、組が出てくる場所 | — |
| 重力 | じゅうりょく | 端末を傾けた方向。ぷにはその向きに落ちる | `gN`, `gDir()` |
| つながり | — | 同じ色のぷに同士がくっついた状態。一度つながると離れない | `bonds` |
| 消す | けす | 同じ色が5個以上つながって、ぷにがはじけること | `findPops` |
| 連鎖 | れんさ | 受付時間のうちに、続けて消すこと。2回目が「2連鎖」 | `chain` |
| 連鎖の受付時間 | — | 次に消すと連鎖がつながる残り時間 | `chainWin(n)` |
| スコア | — | 消した数と連鎖で増える点数 | `score` |

## あそび方の単位

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| ワールド | 5つのステージのまとまり。草原・砂漠など10種類。最後にボスがいる | `THEMES`, `worldNo` |
| ステージ | ワールドの中の1面。「ステージ 1-3」はワールド1の3面目 | `level` |
| ワールドクリア | ワールドのボスを倒すこと | `worldClear()` |
| クリア回数 | そのワールドをクリアした回数。多いほどボスが強くなる | `worldClears[k]` |
| エンドレス | ステージごとにワールドが変わっていく、終わりのないモード | `mode==="endless"` |
| スター | ワールドごとに3つある、クリアのしかたの記録（ボスをたおした・王冠をこわした・缶なしでクリア＝そのプレイ中にエネルギー缶を使わなかった）。全部で30。一度取ると消えず、数に応じてエネルギーの上限とスタート時エネルギーがふえる。記号は ★ | `wstars[k]`, `starsOf(k)`, `starTotal()` |
| ゲームオーバー | 出口がふさがって、次の組が出られなくなること | `gameOver()` |
| ライフ | 1回あそぶごとに1つ使うハート。最大5、20分で1つ回復 | `lives` |
| 放置ペナルティ | 操作しないでいると、お邪魔ぷにが降ってくること | `idleStep` |

## ワールド（10種類）

表の順は、ワールドの番号（1〜10）の順。ワールドをえらぶ画面では、段の順（1段目→2段目）にならぶ。「席」は、ボスの属性と手（ボス戦の章）。

| 番号 | ワールド | キー | 段 | 特徴 | ボス | ボスの席 |
|---|---|---|---|---|---|---|
| 1 | 草原 | `meadow` | 1段目 | ふつうの重さ・ふつうのすべり | ぷにキング | 木のグー |
| 2 | 砂漠 | `desert` | 1段目 | ざらざらで止まりやすい | サンドキング | 土のパー |
| 3 | 氷 | `ice` | 1段目 | つるつるすべる | アイスキング | 水のグー |
| 4 | 炎 | `fire` | 2段目 | 重力が弱い | ファイアキング | 火のパー |
| 5 | トランポリン | `bouncy` | 2段目 | 壁でボヨンとはね返る | ボヨンキング | 金のグー |
| 6 | 宇宙 | `space` | 2段目 | 重力がとても弱い | コスモキング | 月のグー |
| 7 | べたべた | `sticky` | 2段目 | べたべたぷにがたくさん出る（はちみつ） | ハニーキング | 水のパー |
| 8 | ポップコーン | `popcorn` | 2段目 | 壁にふれたぷにが弾け飛ぶ | ポップキング | 火のグー |
| 9 | フラワー | `flower` | 2段目 | はなぷにが出る | フラワークイーン | 木のパー |
| 10 | マグマ | `magma` | 2段目 | マグマぷにが出る | マグマキング | 火のグー |

## ぷにの種類

| 用語 | 意味 |
|---|---|
| ふつうのぷに | 赤・青・緑・黄・紫の5色。同じ色が5個以上つながると消える |
| お邪魔ぷに | 灰色。何個つながっても消えない。となりでぷにが消えると巻きこまれて消える |
| 虹ぷに | どの色ともつながって、いっしょに消える |
| はなぷに | はなぷに同士としかつながらない。3個で消えて、花びらが舞う（フラワーワールド） |
| マグマぷに | だれともつながらない火の玉。ふれたぷにを、まわりごと燃やす（マグマワールド） |
| 特殊ぷに | 爆弾・感染・風船・重り・氷・磁石・時限・べたべた の8種類。ふつうのぷにに力がついたもの |

## ボス戦

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| ボス | ワールドの5ステージ目に出てくる相手。ぷにを消すと体力がへる | `boss` |
| 体力 | ボスのHP。0にすると倒せる | `boss.hp` |
| 王冠 | ボスがかぶっている冠。宝石の力で妨害をしてくる。体力とは別にじょうぶさがある | `boss.crown` |
| 妨害 | ボスがワールドごとにしてくる、じゃまな能力（砂嵐・ふぶき など） | `bossAbility` |
| いじわる光線 | 出口から出る光線。当たるとつながりがこわれる。いまは、ふだんのプレイでは、どのボスも使わない（開発用の切りかえでだけ出る。将来の「ひかり」の席のボスの技） | `beam`, `beamDev` |
| 相性 | あいしょう。道具（アイテム）がボスにどう効くか。道具の席とボスの席から、5通り（特効・封印だけ・王冠だけ・ふつう・同じ席）に決まる。決まりと席の一覧は `TYPES.md`、表は仕様書の相性表 | `aisho(道具, ワールド)`, `AISHO` |
| 席 | せき。属性と手の組み合わせ（「水のパー」など。全部で21）。ボスと道具は、どれかの席にすわる。画面には、属性の字の丸と、手の絵で出す | `BOSS_SEAT`, `ITEM_SEAT`, `seatHtml`, `drawSeat` |
| 属性 | ぞくせい。木・土・水・火・金（五行）と、日・月の7つ。木→土→水→火→金→木 の順に勝ち、日と月はおたがいに勝ち合う（五行と日・月のあいだに勝ち負けはない）。道具の属性がボスの属性に勝つと、王冠を大きくけずる。ワールドのちがい（草原・砂漠…）のことは「属性」と呼ばない | `ELEMS`, `elemWins` |
| じゃんけん（手） | グー ✊・チョキ ✌️・パー 🖐️ の3つの手。グー→チョキ→パー→グー の順に勝つ（どの席どうしでも成り立つ）。道具の手がボスの手に勝つと、妨害を封じる | `HANDS`, `handWins` |
| 特効 | とっこう。じゃんけんでも属性でも勝つこと。妨害を10秒封印して、王冠を15%けずる。ぷに妖精のセリフは「効果ばつぐん！！」 | `aisho()==="sp"` |
| 封印だけ | じゃんけんで勝つ（属性では勝たない）こと。妨害を6秒封印して、王冠を4%けずる。セリフは「封じた！」 | `aisho()==="seal"` |
| 王冠だけ | 属性で勝つ（じゃんけんでは勝たない）こと。封印はせず、王冠を10%けずる。セリフは「王冠に効いてる！」 | `aisho()==="crown"` |
| 同じ席 | 道具とボスの席が同じこと。ほとんど効かない（王冠1%）。セリフは「あまり効いてない…」 | `aisho()==="same"` |
| ふつう | 上のどれでもないこと。王冠を4%けずる。セリフは「効いてる！」 | `aisho()==="normal"` |
| 弱点 | そのボスに特効の道具。ボスによって、1つのことも、まだないこと（宇宙）もある。一度使うまでは「？？？」と伏せてある | `spItems(ワールド)`, `spBosses(道具)` |
| タイプ（裏設定） | 席につけた開発用の名前（たいぼく・いばら など21個）。画面には出さない。`TYPES.md` | — |
| 段 | だん。ワールドをえらぶ画面で、ワールドを2つに分けた、それぞれのまとまり。1段目（草原・砂漠・氷。まずはここから）、2段目（それ以外の7つ。道具をあつめて いどもう）。段でボスの強さは変わらない。前の「相性の階段」（3つの段）は、やめた | `TIER[k]`, `TIER_NOTE` |
| 見破る | ボス戦で特効の道具を初めて使うこと。以後、研究所とワールドをえらぶ画面に、相手・道具の名前が出る | `weakFound`, `weakKnown` |
| 封印 | ボスが妨害できなくなること。特効の道具で10秒、封印だけの道具で6秒。残りが長い封印を、短い封印で上書きしない | `boss.sealUntil` |
| 王冠をこわす | 王冠のじょうぶさを0にすること。以後そのボスは妨害できない | `crownHit` |

## 宝石・アイテム

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 宝石 | ボスを倒すともらえる、そのワールドの色の石。ワールドごとに10種類 | `gems[k]` |
| 虹の宝石 | 王冠をこわして倒すともらえる。どの宝石の代わりにもなる | `gems.rainbow` |
| ぷに研究所 | 宝石でアイテムを開発・強化する場所 | `showMenu("skills")` |
| 開発 | 宝石5個で、新しいアイテムを使えるようにすること | `develop` |
| 強化 | 宝石でアイテムのレベルを上げること | `upgrade` |
| レベル（Lv） | アイテムの強さ。Lv1から始まり、Lv5まで | `lvOf(k)`, `UP_MAX` |
| エネルギー | アイテムを使うための力。ぷにを消すとたまる。記号は ⚡ | `energy` |
| エネルギーの上限 | ためられるエネルギーの最大。100から始まり、スター1つにつき2ふえる（最大160） | `enCap()` |
| スタート時エネルギー | プレイを始めたときのエネルギー。40から始まり、スター1つにつき1ふえる（最大70） | `enStart()` |
| 消費エネルギー | アイテムを1回使うのにいるエネルギー | `enCost(k)` |
| エネルギー缶 | プレイ中に使うと、エネルギーが上限まで満タンになる持ちもの。スロットに置いたボタンを押して使う（1回で1本。開発はいらない）。ショップで買うか、デイリーでもらう（9本まで）。ボタンには持っている本数（×2）が出る。使ったプレイでは3つ目のスターが取れない | `carry.can`, `useCan()`, `canReady()`, `canUsed` |
| コイン | プレイするともらえるお金。ショップで使う | `coins` |

### アイテム（11種類）

| アイテム | キー | 効果 |
|---|---|---|
| ブースター | `boost` | 連鎖の受付時間が2倍になる |
| ストップ | `stop` | 新しい組が出てこなくなる |
| マグネット | `mag` | 同じ色どうしが引き合う |
| シャッフル | `shuf` | ぷにを吸いこんで、ばらまき直す |
| ジャンプ | `jump` | 全部のぷにをはね上げる |
| 魔法の手 | `hand` | ぷにを指でつかんで運べる |
| ほうき | `broom` | ぷにについた べたべた・感染・時限をはらい落として、ふつうのぷにに戻す。舞っている花びらも、はき出す |
| はじけ玉 | `pop` | ぷにがいちばん集まっている所で爆発して、まわりのぷにをお邪魔ぷにごと消す |
| おもし | `weight` | 全部のぷにが重くなって、はずまない・はね飛ばされない |
| ひのたま | `fire` | 凍ったぷにをとかして、お邪魔ぷにを燃やす |
| じょうろ | `water` | 火の粉とマグマぷにを消して、お邪魔ぷにをふつうのぷにに育てる |

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| スロット | アイテムのボタンを置く場所。右手に5つ、左手に3つの合計8か所。アイテム11種とエネルギー缶のうち、えらんで置いたものだけがプレイ画面に出る | `slots`, `SLOT_DEF` |
| アイテム配置 | スロットに置くアイテムを入れ替える画面 | `enterSlotEdit` |
| 時間で効くアイテム | 使うと、決まった時間だけ効果が続くアイテム（ストップ・マグネット・ブースター・魔法の手・おもし） | `itemTot`, `itemClock()` |
| 状態 | ぷにについた、べたべた・感染・時限のこと。ほうきで取れる | `o.sticky`, `o.virus`, `o.timer` |

## そのほか

| 用語 | 意味 |
|---|---|
| ぷに妖精 | ぷにようせい。プレイヤーのそばにいる、小さなぷに。からだの色と、デコでできている（プロフィールに出て、ショップで着せかえる）。プレイ中は、画面の右上（NEXT の箱があった場所）に顔を出して、戦況をセリフと表情（ふつう・よろこび・あせり）で実況する。前は「アバター」（自分のぷに）と「実況ぷに」（みかん色の顔）に分かれていたものを、1つにした。画面では「アバター」「実況ぷに」とは書かない。コード上は `profile.avatar`, `profile.deco`, `fairyLook()`, `drawTalker()`, `say()`, `talk`, `talkMood()` |
| 吹き出し | ふきだし。ぷに妖精のセリフが出る、白地に紺のふちの枠。顔の下に出て、2.3秒ほどで消える。長いセリフは盤面の右上の角に少しかかる。コード上は `#talkBub` |
| セリフ | ぷに妖精が吹き出しで言うひとこと（「効果ばつぐん！！」「封じた！」「王冠撃破！」など）。優先度（上＝相性・王冠・撃破、中＝ボスのようす、下＝ふだん）があり、大事なセリフは下のセリフで上書きされない。一覧は仕様書の「ぷに妖精」の章 |
| デコ | ぷに妖精につける飾り（あたま・かお・とくせい） |
| フレーム | プロフィールで、ぷに妖精のまわりにつく枠 |
| デイリー | 1日1回もらえるごほうび。7日でひとめぐり |
| 図鑑 | 出会ったぷにの記録 |
| 開発版 / 製品版 | 開発版は全部のアイテムやボス戦を試せる。App Store に出すのは製品版 |

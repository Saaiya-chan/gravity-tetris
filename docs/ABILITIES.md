# 能力のネタ帳（タイプごとに3つずつ）

ボスの妨害や、道具の効果を考えるときのネタ帳です（2026-11-21）。
席と相性の決まりは [TYPES.md](TYPES.md) にあります。ここに書いた能力は**候補**で、ゲームに入っているのは ★ のものだけです。

どれも、このゲームの盤面（落ちてくるぷに・つながり・傾き・出口）で起きることとして書いてあります。

## 手ごとのことば

- **グー（塊・圧・重）**: 重装甲・岩塊・衝撃波・押し潰す
- **チョキ（刃・線・貫）**: 鋭利・切断・貫通・狙撃・断ち切る
- **パー（面・網・拡）**: 広範囲・捕獲・霧/液/粉・包み込む・無力化する・封じる

## 作るときの目安

- **手ごとに、妨害の性格がそろう。** グーは「落とす・塞ぐ・揺らす」、チョキは「線で切る・貫く・縫い止める」、パーは「覆う・見えなくする・うつる」。
- **いまあるのは9個**（★）。パーが5、グーが4で、チョキは光線だけ。チョキの能力は、ほぼ全部がこれから作れる。
- **作りやすそうなもの**（いまある仕組みの組み合わせで済む）:
  - 落雷・一閃・流星群 … 光線の向きや本数を変える
  - 落石・氷塊落とし … 消えないお邪魔
  - 暗闇・煙幕・白昼 … 花吹雪と同じ目隠し
  - 延焼・毒霧 … 感染と同じ、うつる仕組み
- **手間がかかりそうなもの**:
  - 石壁・流砂 … 盤面の形を変える
  - 満ち引き … 重力を勝手に動かす
  - 幻 … 偽物の判定
